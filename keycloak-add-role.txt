{} - обозначают, что значение нужно печатать, а не выбирать
--> - нажать на кнопку

1. Run keycloak:
    docker run --name keycloak-hotel-provider -e KEYCLOAK_ADMIN=admin -e KEYCLOAK_ADMIN_PASSWORD=admin -p 18080:8080 quay.io/keycloak/keycloak:23.0.6 start-dev

2. Запустить localhost:18080
	2.1 Зайти в Админ-консоль, admin/admin
	2.2 Создать новое пространство (нажать на master --> create realm --> ввести только `Realm name` = hotel-realm, например)

3. Realm -> Realm-setting -> Login:
    Выбрать (Login screen customization):
    - User registration: On
    - Forgot password: On (по желанию)
    - Remember me: On (по желанию)

3. Создать клиента. Clients --> Create Client
	-1 General settings:
		Client type: OpenID Connect
		ClientID: {hotel_registration_admin}
		Name: {Spring Boot Admin Client}
		Always display in UI: Off
		--> next
	-2 Capability config:
        Client authentication: ON
        Authorization: OFF
        Authentication flow: выбрать
            Standard flow: ON
            Service accounts roles: ON
		--> next
	-3 Login settings:
		--> Save

4. Добавить роль для возможности добавления ролей: Clients → spring-app → Service account roles
    - клацнуть по "Assign role"
    - переключиться с "Filter by realm-role" на "Filter by clients"
    - выбрать роли:
        - manage-users (экран 2 в списке)
        - view-users (экран 3 в списке)
        - view-realm (для назначения ролей)
        - query-users (желательно)
      --> Assign

5. Скопировать секрет Clients → spring-app → Credentials (UIyn2JXR0J5x7nrQwTACGx11ICLQuZHr)

6. Создать роль - слева вкладка "Realm roles" --> "Create role":
   	"Role name": {hotel_data_reader}
   	"Description": {Role for remote Services for reading data of hotel-provider Service}
       	--> Save
   	"Role name": {hotel_data_writer}
    "Description": {Role for remote Services for reading and changing data of hotel-provider Service}
        --> Save
    "Role name": {hotel_registration_admin}
    "Description": {Role for hotel_registration (Admin)}
        --> Save
    "Role name": {hotel_registration}
    "Description": {Role for remote services for call hotel_registration}
        --> Save

7. Добавить роль добавляемую при регистрации: Realm settings --> User registration
    - Assign role

8. Для получения Bearer-токена нужно
curl -X POST \
  http://localhost:18080/realms/hotel-realm/protocol/openid-connect/token \
  -d grant_type=client_credentials \
  -d client_id=spring-app \
  -d client_secret=UIyn2JXR0J5x7nrQwTACGx11ICLQuZHr

9. Скопировать конфигурацию себе на комп (потом переместить в папку проекта ./config/keycloak)
    9.1 Создать файл-конфиг внутри контейнера (keycloak-sandbox - это имя контейнера):
        docker exec keycloak-sandbox /opt/keycloak/bin/kc.sh export --dir /opt/keycloak/data/export --realm sandbox --users realm_file   - работает
    9.2 скопировать на комп (в папку юзера):
        docker cp keycloak-sandbox:/opt/keycloak/data/export/hotel-realm.json ./hotel-realm.json
