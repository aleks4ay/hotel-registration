# hotel-provider
Part of Hotel microservices

## Keycloak registration
- При регистрации нового пользователя создается запись в Keycloak (в докере)
- Spring Boot:
  - показывает страницу регистрации
  - редиректит в Keycloak
- Keycloak:
  - регистрирует пользователя
  - хранит пароль
  - назначает роли

## Roles
- Переход на сайт регистрации будет доступен приложениям, чей клиент имеет роль hotel_registration
- После регистрации будет перенаправление обратно на вызывающий сайт

## Управление
- Есть зарегистрированный в Кейклоаке клиент с ролью hotel_registration_admin
  - он создает новых юзеров. С ролью hotel_data_reader
  - для добавления роли hotel_writer будет отдельный эндпоинт
